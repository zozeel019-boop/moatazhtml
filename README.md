# NEON STAY PRO — نظام إدارة الفندق

واجهة عربية متجاوبة لإدارة الحجوزات والغرف والنزلاء ومتابعة مؤشرات الفندق.

## التشغيل

عند ترك إعدادات Supabase فارغة، افتح `index.html` مباشرةً لتجربة النسخة المحلية. بيانات هذا الوضع محفوظة في المتصفح الحالي فقط.

## ربط Supabase

1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor وشغّل محتوى [`supabase-schema.sql`](./supabase-schema.sql). ينشئ ذلك جداول الحجوزات والصيانة، ويفعّل سياسات RLS لعزل بيانات كل حساب، ويمنع تعارض حجوزات الغرفة في الفترة نفسها، ويضيف الجداول إلى بث Realtime.
3. انسخ Project URL والمفتاح العام `anon` أو `publishable` إلى `supabaseUrl` و`supabaseAnonKey` في [`config.js`](./config.js). المفتاح العام مخصص للمتصفح؛ **لا تضع `service_role` أو أي مفتاح سري في هذا الملف**.
4. شغّل المشروع عبر خادم تطوير محلي مثل VS Code Live Server، وأضف عنوانه إلى قائمة Redirect URLs في إعدادات المصادقة في Supabase.
5. افتح التطبيق، ثم أنشئ حساب مدير من شاشة الدخول. إذا كان تأكيد البريد الإلكتروني مفعّلًا، أكّد البريد قبل تسجيل الدخول.

بعد إعداد Supabase، تستخدم الحجوزات وحالات الصيانة قاعدة البيانات السحابية وتُحدّث البيانات بين الجلسات لحساب المستخدم نفسه. سجلات العرض الموجودة في الوضع المحلي لا تُنقل تلقائيًا إلى قاعدة البيانات.

## الوظائف

- لوحة مؤشرات للحجوزات والإشغال والإيرادات.
- إضافة حجوزات مع التحقق من توفر الغرفة وتعارض مواعيد الإقامة.
- تسجيل دخول النزيل ومغادرته، وإدارة حالة الغرف والصيانة.
- البحث والتصفية، وعرض سجل النزلاء وتقارير الفندق.
- تنزيل تقرير الحجوزات بصيغة CSV.

من دون إعداد Supabase، يعمل التطبيق ببيانات تجريبية محلية ولا يتضمن تسجيل دخول فعليًا. لا تستخدم هذا الوضع لتخزين بيانات نزلاء حقيقية.
